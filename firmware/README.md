# ファームウェア

StopWatch C152 向けファームウェアです。アバター描画、タッチ、音声入出力、接続管理を行います。

## 音量

A ボタン（GPIO2、黄）で音量を上げ、B ボタン（GPIO1、青）で下げます。物理配置に対する割り当ての手触りは実機で未確認です。単押しで1段変わり、押し続けると400 ms後から連続して変わります。繰り返しの間隔は200 msから始まり、段階的に50 msまで縮みます。上限は毎秒20段で、値0から255までは約3.3秒です。

音量は52段階（段0〜51）です。段 `k` の値は `5k` で、段0は無音です。既定は段26、値130、約−11.8 dBです。値はNVSへ保存しません。電源投入時は毎回既定値から始まります。確認音と音量バーはありません。

顔、目、リング、点の寸法は音量に合わせて変わります。値0では顔の半径が約73.7 px、値130では約151.8 px、値255では200 pxです。表示と音声の計算式は[アバター仕様](../docs/AVATAR_SPEC.md)と[Phase 3仕様](../docs/PHASE3_SPEC.md)を参照してください。

ボタンと描画のロジックは `grokwatch_core` にあります。GPIOは10 ms周期で直接読みます。スピーカーとマイクの操作は `audio_task.cpp` に集めています。録音を始める前に再生を止めます。

## 検証

自動テストとファームウェアのビルド結果は[テスト報告](../docs/TEST_REPORT.md)に記録します。StopWatch C152での音量、音質、表示、ボタン、タッチ、音声切り替えは未確認です。
