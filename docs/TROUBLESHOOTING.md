# トラブルシューティング

Phase 3 以降の確認結果を基に手順を追記する。

| 症状 | 確認する項目 |
| --- | --- |
| Disconnected が続く | 端末の Wi-Fi、ゲートウェイのヘルス、トークン設定と再認証の状態。 |
| Thinking から進まない | ルーチンの起動結果、Tailscale の経路、返信受け口の到達性、返信トークンの期限。 |
| 音声が聞こえない・拾えない | 入出力の設定、ASR / TTS の状態、フレーム送受信、端末の音量。 |
| タッチに反応しない | C152 の画面座標、状態表示、ドラッグとスワイプの判定。 |
| USB 書き込みで止まる | 対象機種、ダウンロードモード、承認とバックアップの状況。 [書き込み手順案](FLASHING.md) |

共有するログは [セキュリティ方針](../SECURITY.md) に従う。
