# Phase 5 書き込みと復旧の手順案

**承認前は実行しない。** 実施前に対象機種・ハードウェア版、USB ポート、バックアップの保存先、書き込み範囲、データへの影響、復旧方法を示し、承認を得る。この手順は未実機検証。

1. 対象が M5Stack StopWatch C152（ESP32-S3、16 MB フラッシュ）であることを確認する。C152 専用の成果物とパーティション表を照合する。機種や版が曖昧なら停止する。
2. USB-C を接続し、電源ボタンを長押しして緑 LED の点滅を確認する。ダウンロードモードの手順は [M5Stack 公式仕様](https://docs.m5stack.com/en/core/StopWatch) を参照する。
3. フラッシュ全体を読み出す。保存先はリポジトリ外のアクセスを制限したディレクトリを指定する。サイズが 16 MiB であることを確認し、チェックサムと対象との対応を非公開で保管する。

   ```bash
   umask 077
   esptool --chip esp32s3 --port '<usb-port>' read_flash 0 0x1000000 '<private-backup-dir>/factory-backup.bin'
   ```

4. バックアップが読め、書き込み範囲が既存の NVS と工場データを上書きしないと確認できた場合だけ進む。フラッシュ全体の消去、NVS 消去、別機種用バイナリの書き込みは禁止する。成果物が確定したら、フラッシュオフセットと書き込みコマンドを記録する。
5. 書き込み後に機種表示、アバター、タッチ、音声、Wi-Fi 復旧、伝書鳩の既存 Skills を確認し、結果を [テスト報告](TEST_REPORT.md) に記録する。

## ロールバック案

異常があれば稼働を止め、同じ端末用のバックアップとチェックサムを照合する。復旧書き込みの影響を示して承認を得た後、ダウンロードモードから同じ端末の元イメージをオフセット `0` に復元する。元の起動とデータを確認する。バックアップと実機ログは非公開で保管する。

全フラッシュの読み出しと復元の考え方は、別機種を対象とする [openai-live-esp32 の StackChan 手順](https://github.com/openai/openai-live-esp32/tree/6520b96840493c285ecbb7c72cace3b8116b619d/examples/stackchan) を参照した。
