# セットアップ

Phase 3 で構成が確定したら手順を記載する。現時点は準備中。

| 項目 | 記載予定 |
| --- | --- |
| 開発環境 | ESP-IDF 5.5、C152 ターゲット、Python ゲートウェイと各依存関係の導入方法。 |
| 設定 | [設定例](../config/.env.example) を基にローカルの `.env` と macOS Keychain を設定する方法。 |
| ローカル確認 | `mock` アダプタでゲートウェイを起動し、ヘルスと音声経路を確認する方法。 |
| webhook | 伝書鳩のルーチン設定と、Tailscale 経由の返信経路の確認方法。 |
| 任意の CLI | 採用時に利用者が別途導入する `gbot_cli` の切替と無効化方法。 |
| 運用 | 起動、停止、更新、アンインストール。常駐化は Phase 6。 |

対象環境と監査状況は [環境](ENVIRONMENT.md)、書き込みは [Phase 5 の手順案](FLASHING.md) を参照する。
