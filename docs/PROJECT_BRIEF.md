# プロジェクト概要

GrokWatch は M5Stack StopWatch C152 を、Mac mini 上の Grok Bot「伝書鳩」の音声とタッチの端末にする。端末は 466×466 の丸型画面、タッチ、マイク、スピーカー、接続管理を担当する。会話、記憶、Skills、タスク実行は既存の伝書鳩が担当する。

日本語の会話は「Hi Grok」またはタッチで始める。アバターは常に動き、視線、瞬き、ドラッグ追従、ジェスチャーと会話状態への反応を持つ。Wi-Fi 切断とゲートウェイ再起動から復旧できるようにする。伝書鳩は環境変数 `GROKWATCH_AGENT_ID` で指定する。

| フェーズ | 完了条件 |
| --- | --- |
| 0 環境監査 | Mac mini と既存環境を読み取りで棚卸しし、[環境](ENVIRONMENT.md) に記録する。秘密の値は記録しない。 |
| 1 公開準備 | 新規 Public リポジトリ `GrokWatch` の公開先、公開範囲、初回投入内容を確認する。公開前に秘密・個人情報とライセンスを検査する。 |
| 2 調査 | 先行実装と C152 仕様を比較し、動画の観察結果を受入条件にする。交換可能なブリッジの方式を選ぶ。 |
| 3 実装 | ファームウェア、ゲートウェイ、ブリッジを実装する。既存 Grok Bot の設定とサービスを保護する。 |
| 4 ビルド・自動テスト | C152 ビルドと接続、認証、描画、状態遷移の自動テスト結果を記録する。 |
| 5 実機確認 | 承認後にバックアップと書き込みを行い、アバター、タッチ、日本語音声、既存 Skills、再接続を実機で検証する。 |
| 6 運用・公開整備 | 専用 LaunchAgent、停止と復旧、ログローテーション、公開手順を整える。 |

作業状況は [進捗](PROGRESS.md) に記録する。ビルド結果と実機結果は別に記録し、Phase 5 の受入条件を満たして MVP 完了とする。
