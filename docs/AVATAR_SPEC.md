# アバター仕様

466×466 の円形ディスプレイに、黒背景、中央の白円、黒いカプセル型の目二つを自作描画する。見た目と動きの根拠は [参照動画の観察記録](AVATAR_REFERENCE.md) に記載する。座標、色、曲線は GrokWatch 独自の実装として MIT で公開する。

| 状態・入力 | 根拠 | 表現と受入条件 |
| --- | --- | --- |
| Idle | 動画由来 | わずかに漂う視線と自然な瞬きを繰り返す。30 秒以上の観察で静止画にならず、継続再生する。描画負荷も記録する。 |
| Listening | 追加要件・自作案 | 目を少し大きく開き、白円の外周に細いリングを表示する。録音可能な間だけ表示し、入力中と判断できる。 |
| Thinking | 追加要件・自作案 | 目が緩やかに左右へ動く。通信待ちでも描画とタッチが止まらず、Listening と区別できる。 |
| Speaking | 追加要件・自作案 | 再生音の振幅に合わせてリングを変化させる。音声が止まると変化が止まり、次の状態へ移る。 |
| タップ | 瞬きは動画由来。タップ方向への移動は開発要件。 | タップ位置に視線を向け、即座に一度瞬く。開発要件の短いリアクションはこの瞬きで満たす。 |
| ドラッグ | 動画由来。画面端の制限は追加要件。 | 指の移動に滑らかに追従し、左右の目を非対称に変形する。画面端で座標を制限し、離したら現在の会話状態の視線に戻る。待機中は Idle に戻る。 |
| 長押し | 追加要件。動画では指の位置への注視のみ。 | 長押しで会話開始を要求する。受付時は Listening に遷移して入力中の表示を出す。停止にも割り当てる場合は状態ごとの動作を統一する。 |
| スワイプ | 追加要件・自作案 | スワイプ成立時に視線を進行方向へ短く移して戻す。モード切替を採用する場合は距離・方向・速度の閾値を定め、連続ドラッグと区別し、切替対象を明示する。 |
| Disconnected | 追加要件・自作案 | 灰色の断続リングで接続断を示す。接続と認証が復旧したら Idle に戻る。 |
| Error | 追加要件・自作案 | 短い警告色のリングで処理エラーを示す。復旧後は Idle に戻り、通信断の表示と区別できる。 |

## 視線と目の変形案

白円の中心を `c`、追従を最大にする半径を `r` とする。タッチ座標 `p` から `u = (p - c) / r` を求め、`g = u / max(1, |u|)` で単位円の内側に制限する。ドラッグ中は `g` を平滑化し、両目を `g` の方向へ動かす。目や移動量が白円の内側に収まるようにパラメータを設定する。

左目は `s = -1`、右目は `s = 1` とし、横向きの変形を `d = s × g_x` とする。基準幅 `w0`、基準高さ `h0` に対し、`幅 = w0 × (1 - a × d)`、`高さ = h0 × (1 + b × d)` とする案。係数 `a` と `b` は正の小さい値とし、視線に近い側の目を細く、長くする。瞬きは高さに別の係数を掛け、短時間だけ線に近づける。係数と遷移時間は実機で調整する。

## 音量に連動する大きさ

音量値 `v` は `M5.Speaker.setVolume` に渡す値で、0〜255です。顔の大きさは音量値に応じて面積が直線に変わるように計算します。

```text
A0 = 0.1 × 233² / 200²
s(v) = sqrt(A0 + (1 − A0) × v / 255)
顔の半径 = 200 × s(v)
```

`v=0` で顔の面積は画面面積の10 %、顔の半径は約73.7 pxです。既定値 `v=130` では半径約151.8 px、`v=255` では現在と同じ200 pxです。目の位置と寸法、リング、Thinking の点も画面中心を基準に同じ倍率で変えます。目の最小寸法は幅4 px、高さ2 pxです。リング幅と点半径は2 px以上です。

ホストテストは値0、中間値、255の寸法と各状態の描画範囲を検査します。端末上の見た目と視線の手触りは未確認です。

## 受入確認

- 四方向の縁付近と中央にタップし、視線の方向と瞬きを確認する。円外相当の四隅も座標変換の入力に与え、安全にクランプされることを確認する。
- 連続ドラッグ、縁の一周、指の解放、長押し、スワイプで反応と遷移を確認する。
- 音声応答中と Wi-Fi 切断中にタッチし、視線が追従し、会話・接続状態の表示が維持されることを確認する。
- Idle を 30 秒以上観察し、撮影ログを非公開で保管する。描画 fps、CPU、メモリ使用量を測り、性能目標は実測後に設定する。
